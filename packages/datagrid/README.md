# @testproject/datagrid

Paczka workspace z `DataGrid`, typami i stylami.

Aktualnie `frontend` uzywa jej lokalnie przez workspace alias:

- `@testproject/datagrid`
- `@testproject/datagrid/styles.css`

Build paczki:

```sh
npm run build
```

Artefakty laduja w `dist/`:

- `dist/index.js`
- `dist/index.cjs`
- `dist/index.d.ts`
- `dist/styles.css`
